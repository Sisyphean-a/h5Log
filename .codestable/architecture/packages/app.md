# 应用

scope: package:app
context: [remote-logging](../../requirements/contexts/remote-logging.md)

## 边界

一个 Node.js 进程接收与保存日志、按查看范围分发给查看者，并托管 Vite 构建的工作台页面。服务端日志只存在内存，不拥有 Android 设备或业务登录会话。工作台按客户端定位日志，不承担监控分析或远程操控手机；工作台使用相对路径，支持根路径或由反向代理去除前缀的子路径部署；服务自身仍提供根路径 API。

## 入口与契约

- src/log-route.ts、src/server/index.ts、src/web/App.vue：工作台路径可用 `console`、`interface`、`error` 和可选关键词初始化来源与搜索；服务端对这些路径返回工作台并设置相对基址，保证反向代理子路径下资源和接口仍指向部署目录。路径不控制其他筛选，门禁仍生效。
- src/log-filter.ts、src/search-query.ts：服务端快照、工作台 SSE 增量与本地历史共用的匹配规则。会话目录只受 appId、environment、clientKey 范围约束，日志行再按会话、级别、来源和搜索筛选；source 查询值以逗号分隔时取来源并集，空值表示不限来源。搜索仍只匹配 args 的 JSON 文本，去首尾空白且忽略大小写；沿用 logcat 的 &&（且）、||（或）与词首 -（非），&& 优先，普通文本的空格不拆词，不解释括号、正则或字段语法。输入中的空项被忽略，没有有效项时按完整字面文本匹配；同一个编译器提供正向去重高亮词，避免查询、预览与高亮语义分叉。匹配器固定一次查询的条件，分页游标与清空水位仍由各自调用方掌握。

日志服务：

- src/server/index.ts：createLogServer；POST /api/logs 整批校验后写入，GET /api/logs 筛选分页和返回范围内会话，GET /api/logs/:id 返回日志及同客户端同会话的关联请求，GET /api/stream 分发事件，GET /api/health 返回保留资源与运行状态。
- src/server/store.ts：LogStore 拥有接收时间、过期（默认 12 小时，`RETENTION_HOURS` 可配）、条数/字节淘汰（默认 8,000 条 / 16 MiB）、保留窗口内去重、客户端与会话聚合、请求关联。id 用于本进程分页，serverId 区分重启。淘汰的数组槽立即解除日志对象引用，并按游标分段压缩。
- src/server/cli.ts：监听和关闭，读取 `PORT`、`HOST`、`MAX_LOGS`、`MAX_MEMORY_MB`、`RETENTION_HOURS`、`ALLOWED_ORIGINS`，托管构建后的 dist/web。容量上限保持保守默认值，内存占用落在几十 MiB；调大上限才需要放宽 V8 堆参数。SIGINT/SIGTERM 等待连接关闭，五秒后关闭剩余连接。
- src/server/index.ts：上传支持普通 JSON 与 gzip，压缩输入和解压结果都限 1 MiB，损坏编码显式报错，整批校验后才入库；跨域预检允许 Content-Encoding。查询 JSON 在达到 1 KiB 且客户端接受 gzip 时异步压缩。SSE 正文只按 appId、environment、clientKey 范围分发，忽略阅读筛选；目录全局可见，同批 logs 携带目录与淘汰水位，不再额外重复发送 clients。SSE 按 Accept-Encoding 协商 gzip，每次写入使用 Z_SYNC_FLUSH；慢消费者的压缩与响应缓冲合计受限，一个查看者断开不影响其他查看者。未指定范围仍订阅全部。
- 清理事件把服务端 expiresBefore 和容量淘汰游标 evictedThroughId 发给工作台，服务端视图立即丢弃已经淘汰的行，只在当前行被清理时补读列表并复用其索引；当前会话计数与客户端目录不一致时合并刷新索引，无关设备的淘汰不触发查询。读取期间水位变化仅在响应中确有已淘汰行时再补读；本地历史页不套用这些水位或回读服务端覆盖。服务端保留期限不依赖查看者电脑时钟。来源白名单是 CORS 控制，不是身份认证；首版没有内置用户或权限系统，部署入口归反向代理。

工作台（Vue 3 + Naive UI，组件按需引入，状态集中在 src/web/workbench.ts）：

- src/web/App.vue、src/web/components/*：顶部仅一行工具栏承载设备、关键词、彩色级别与来源多选；隐藏其他设备、跟随、更早/最新/清空视图与服务状态使用带可访问名称和悬停提示的 SVG 图标，窄屏保持单行横向滚动。移除左侧栏、Logo、条数、连接状态文字与接入 SDK/复制列表/导出列表入口，详情复制保留；服务图标表达工作台与服务的连接状态，不代表设备在线；状态面板分别显示电脑连接、最近收到推送与所选设备最近上报时间，错误与本地历史仍显式反馈。日志为主视线，详情是右侧停靠面板，分隔条支持指针拖拽与键盘调整宽度，两侧保留最小阅读空间，宽度偏好持久化到浏览器 IndexedDB，下次打开恢复，不随日志清空或服务重启重置；900px 及以下改为全屏覆盖并隐藏分隔条；颜色由工作台令牌与 Naive UI 主题覆盖统一，列表不设级别列或色点，由来源文字颜色表达级别，窄屏也保留来源；悬停、关联与选中使用逐级加深的底色，列表保留请求关联线。接口摘要只突出查询参数前的末段路径，方法、路径前缀与参数弱化；其他日志仍对前缀标签、URL、请求方法、错误关键词、耗时、路径和源码位置做轻量高亮，搜索命中加底色。来源候选仅控制台、异常与接口，移除的只是自定义筛选入口，不限制既有 custom 日志的采集或读取。
- src/web/access.ts、src/web/components/AccessGate.vue：日志加载前显示全屏毛玻璃门禁；密钥由构建时的 `VITE_ACCESS_KEY` 注入（未配置时用公开默认值 2468，改为只保留数字/字母，大小写不敏感），通过后把解锁状态写入独立 IndexedDB（h5-log-access），之后打开直接进入。未解锁时不建立 SSE、不读取日志，工作台内容保持模糊且不可聚焦；存储不可用时仍允许本次进入并明确提示。密钥会随构建进入前端 JS，门禁只在前端校验，GET /api/logs、/api/stream 等接口不校验密钥，不能替代反向代理认证。
- 默认聚焦一个设备：加载后自动选中最近上报的客户端，切换入口在顶部工具栏；不需要先筛应用/环境就能看日志。页面会话不再是工作台的选择项，但协议字段、内部索引与请求关联约束保持不变。
- src/web/components/LogList.vue：按当前可见日志顺序，为每台设备首次遇到的采集添加“开始上报”，后续首次遇到的新采集添加“重新开始上报”；交错返回的已知采集不重复提示。分隔行只属于阅读视图，不新增日志、不影响条数、搜索、复制或导出；不标注真实启动时间，不推断断开。
- 关键词在同一个输入框完成：App.vue 用输入草稿立即过滤并高亮当前页，250 毫秒防抖后再向服务端收窄窗口；同设备筛选保留当前页供预览，不把网络等待变成清空再重建，切换设备仍立即清空旧范围。workbench.ts 的日志正文是只读快照，窗口通过 shallowRef 整体替换；避免深层响应式代理让大正文的 JSON 搜索遍历阻塞主线程。SSE 新日志只有命中已提交筛选才进入列表，再由输入草稿过滤。实时增量由 Vue 响应式渲染，不再手工重排 DOM。
- src/web/workbench.ts：筛选、游标、分页、SSE 合流、详情与本地历史的状态机；组件只读状态，测试直接驱动该状态机。订阅随设备范围切换，关键词、级别、来源与会话不触发重订阅；本地历史只保存实际订阅或查询收到的正文。服务端每 15 秒的 clients 事件兼作可观测心跳，45 秒无事件则重建流，重新联网或恢复可见也重建；hello 后补读当前服务端页或本地历史页，旧流事件仍无效。查询连同正文限时 10 秒，即使底层不响应取消也可结束；失败保留缓冲内增量，暂存或销毁时取消请求与检测定时器。查询期间按当前筛选缓存最多 200 条匹配日志，全局游标独立推进，缓冲溢出仍保留历史入口。生命周期区分运行、暂存与最终销毁：进入后退缓存调用 suspend 关闭流并作废旧请求，resume 重建连接并恢复当前服务端或本地历史页，dispose 后不能重新恢复；旧连接事件和暂存前的迟到响应不会更新当前视图。历史页停留时继续接收连接更新，回到实时后重新读取最新页。App.vue 的跟随监听最后可见事件与 serverId，不依赖总条数，200 条窗口替换旧行后仍在 DOM 更新后滚到底部；恢复跟随立即到底，暂停及本地历史模式不自动滚动。滚动只改变位置，不自动翻页；“更早”手动读取上一页，没有服务端或本地更早记录时禁用入口。空历史响应保留当前页与加载期间的实时增量；服务实例变化则清空旧页和旧分页游标，不能保留旧实例记录。App.vue 同步监听 serverId 变化，先暂存旧工作台停止 IO，再整页刷新以加载发布后的资源；首次连接及同实例重连不刷新。设备目录缺项时选择框显示占位，不回显内部 JSON key。
- src/web/history.ts：复用既有 h5-log/meta 存储的 ui:detail-width 键保存详情宽度，不升级库版本或改动日志分区。把收到的日志旁路写入 IndexedDB（默认 50,000 条 / 64 MiB，按条数与字节淘汰最旧记录，写入按 150 毫秒或 200 条批量提交）。按 `[serverId, id]` 分区，同页待写记录按 id 合并；覆盖、真实新增条数/字节差额、淘汰及 meta 计数共用读写事务，不使用页面私有容量计数。meta/accountingVersion 标记一次性校准旧计数，不升级数据库版本，保留有效当前分区日志与宽度偏好；校准不能恢复已经误删或识别过去被错误标记实例的日志。批次绑定实例与 generation，重启丢弃未提交旧批次，跨页迟到写入不能切回旧实例；后台写入串行，销毁后不再重开连接。浏览器不支持时返回 undefined；运行期存储失败显式报告，读取拒绝，不伪装为空历史。服务端窗口翻尽后“更早”转入本地历史，同一筛选谓词在本地库上继续分页，并明确提示数据来自当前浏览器及如何返回最新日志。本地存档受自身容量和 serverId 分区约束，不受服务端 12 小时窗口或容量淘汰水位清空；清理通知不会关闭本地页的选中记录。
- src/web/format.ts：列表摘要、HTTP 收发摘要、时间与级别/来源文案的唯一实现。
- src/web/components/LogList.vue、src/web/App.vue、src/web/log-copy.ts：日志行右键先复用左键选中与即时详情，再从当前条目解析复制菜单，不等待后台关联查询。请求提供请求头、请求体与 cURL；响应及接口错误提供响应头、响应体，未采集字段禁用，不借用关联记录。cURL 按页面地址补全相对 URL，保留已采集查询参数、头与正文，使用 POSIX shell 单引号转义。其他来源提供完整正文复制，不使用列表截断摘要。控制台首个字符串符合 `[埋点] 描述 | 标识` 时增加复制埋点；仅当标识具有单一 `h5_` 前缀或 `_h5` 后缀且去除后非空时提供复制原始埋点，不改中间内容、不猜测双标记。选中条目后的 Ctrl+C / ⌘C 默认复制完整正文，可解析原始埋点时优先复制原始埋点；输入框与可编辑内容保留浏览器复制行为。复制失败显式提示；Escape 先关闭菜单而不关闭详情，外部点击、滚动、失焦、窗口变化及条目失效均关闭菜单。
- src/web/components/HttpDetail.vue：接口对象按紧凑概览、查询参数、头信息、正文和错误分区，缺失字段不占位；查询参数保留同名项，0、false、null 与空字符串可见。协议层 requestId 不在阅读视图展示，只保留作内部关联与原始复制；不删除业务正文中的同名字段。其余扩展字段及附加输出保留为次要信息；普通日志仍走 JSON 阅读视图。
- src/web/workbench.ts 的 openDetail 立即使用当前列表中的完整日志与已有同客户端同会话 HTTP 关联记录更新详情，不等待网络往返，也不保留上一条正文；后台详情请求只补全关联记录并校验事件身份，失败显式提示且保留当前本地正文。详情按请求标识读取同一客户端与会话内的收发记录，迟到响应不会覆盖当前选择，重启后 eventId 不匹配则拒绝采用响应；选中记录被淘汰时明确提示。详情常规元信息展示接收时间、合并的应用设备（应用 / 环境 · 设备）和页面，页面地址完整换行、不做省略；不再单列与内容重复的“请求”元信息行或关联请求列表；复制 JSON 仍保留原始日志（包括 sessionId）及关联记录。JSON 阅读视图展开完整对象/数组字符串，支持日志前缀与嵌套字段；普通文本与无效 JSON 保留原文，不改变原始日志、搜索、复制或导出。按词法着色（键、字符串、数字、字面量、标点），文本节点渲染不拼 HTML；超过 20,000 字符退化为纯文本，避免单条日志生成数千节点。
- 会话计数基于服务端日志页快照和其后的 SSE 增量；迟到的快照范围内事件按全局 id 游标忽略。加载期间按事件 id 去重并计数，不因显示缓冲截断而少计；容量淘汰按受影响范围定向补读，不替换本地历史页；增量缓冲溢出时刷新索引。索引查询单路合并，响应只在页面版本与会话 revision 均有效时采用，期间有新增量则重读；索引计数游标独立于日志游标，快照已包含而尚未推送的事件不重复计数。服务器重启后分页 id 与容量淘汰水位同时重置。
- 日志内容由 Vue 文本绑定渲染，不执行日志中的 HTML。设备状态只描述最近上报，不伪造在线/离线。
- demo.html、src/web/demo.ts：真实 SDK + Axios 接入演示，不伪造工作台日志。

构建：服务端由 vite.config.server.ts 打包为自包含单文件 dist/server/cli.mjs（只外部化 node: 内置模块），页面由 vite.config.ts 构建到 dist/web；dist 就是部署产物，运行时不需要 node_modules。

运行配置与代理示例见 [根 README](../../../README.md#部署)，契约证据在 packages/app/test/。
